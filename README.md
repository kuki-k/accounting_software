# accounting_software

家計・家庭向けの管理アプリです。

## 家庭ライフスペース

インボックスにメモを入れると、日付や金額を読み取って **今月 / 3ヶ月以内 / 今後** に整理します。

### 使い方

1. **インボックス**にメモを書く（厳密な入力欄は不要）
2. 必要ならプリント写真・PDF・リンクを添える
3. **整理して反映** を押す
4. 下のタイムライン（今月 / 3ヶ月以内 / 今後 / 日付なし）に振り分けられる

### メモの例

```text
幼稚園の遠足 10月3日 お弁当持参
祖母の誕生日は3月3日
おじいちゃんからお年玉 1万円もらった
Netflix解約は来月末までに判断
https://example.com/print.pdf
```

読み取りの目安:

- 日付: `10月3日` / `来月末` / `2026-08-12` など
- 金額: `1万円` / `1490円` / `¥1,490`
- 人物: `祖母` / `○○さん` / `長男`
- ラベル: サブスク・誕生日・幼稚園・学校・親戚・お年玉など（キーワードから推定。自由追加も可）

写真やPDFは関連ファイルとして残します。プリント文字の自動OCRは今後の拡張で、現状はメモ欄に要点や読み取りテキストを貼ると整理精度が上がります。
