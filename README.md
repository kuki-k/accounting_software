# accounting_software

家計・家庭向けの管理アプリです。

## 家庭ライフスペース

サブスク解約の目安、誕生日、子どもの行事、旅行、資金繰りなど、家庭で忘れずに押さえたいことをまとめるスペースです。

- 項目の追加・完了・削除
- **自由ラベル**（候補あり。限定列挙ではなく、任意のラベルを追加可能）
- 日付・金額（任意）・担当者
- ラベル / 担当 / 状態での絞り込み
- ブラウザの `localStorage` に保存

### 開発

```bash
npm install
npm run dev
```

### ビルド

```bash
npm run build
npm run preview
```
